# Support

narad-go is maintained by one person, alongside the Narad broker. Support is
best-effort and community-driven.

## Questions and usage help

Use the Narad Discussions board, which covers the client too:

https://github.com/DebanganThakuria/narad/discussions

Include the narad-go version, the Narad broker version, your Go version, the
client options you set, and the smallest code that shows the problem.

Most usage questions are answered by the [README](./README.md), the API
documentation on [pkg.go.dev](https://pkg.go.dev/github.com/debanganthakuria/narad-go),
and the [Go client guide](https://debanganthakuria.github.io/narad/build/go-sdk/)
in the Narad docs.

## Bugs

Use the bug report template for reproducible client issues:

https://github.com/DebanganThakuria/narad-go/issues/new/choose

A problem in the broker itself (wrong status codes, lost or duplicated
messages that the client did not cause) belongs in the
[Narad repository](https://github.com/DebanganThakuria/narad/issues/new/choose).

## Security

Do not report vulnerabilities in public issues or discussions. Follow the
private process in [SECURITY.md](./SECURITY.md).
